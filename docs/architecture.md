# LatentMind 技术架构文档

## 1. 核心概念

### 1.1 什么是"机器潜空间语言"

HRM-Text 和 GRAM 的核心创新是：让模型在高维隐状态空间中进行多步循环迭代（Recursive Iteration），而不是输出大量离散的文本 Token。

- **传统 CoT**：模型生成大量中间文本 Token 来"思考"（浪费参数量和算力）
- **机器潜空间语言**：模型在内部通过 Hidden States 进行逻辑推演、跨模态对齐和因果计算
- **参数复用**：同一个 Transformer/SSM 层在潜空间内循环 K 次，物理参数只有 1B，但等效计算深度达到 K×

### 1.2 HRM-Text vs GRAM

| 维度 | HRM-Text | GRAM |
|------|----------|------|
| **推理方式** | 确定性递归（单一路径）|随机多轨迹（多条路径）|
| **核心创新** | 分层递归 + MagicNorm | Stochastic latent trajectories |
| **适用场景** | 结构化推理（数学、代码）| 多假设推理（规划、不确定性）|
| **对你的价值** | 提供 latent space 推理框架 | 提供多轨迹概率推理 |

### 1.3 两者结合

HRM-Text 提供了"如何做 latent space 推理"的基础框架，GRAM 提供了"如何做多假设探索"的能力。两者叠加才是完整的 Latent-Native Multimodal 架构。

## 2. 架构详解

### 2.1 模块 A：原生统一感知层（~150M）

**设计**：借鉴商汤 SenseNova U1 的 NEO-Unify 架构思想，使用极轻量的 3 层 CNN 将图像 Patch 和文本 Token 直接映射到同一个潜空间表示中。

**特点**：
- 无独立视觉编码器（VE-free）
- 像素和文字从一开始就在同一个空间"对话"
- 消除了跨模态翻译的信息损耗

### 2.2 模块 B：分层递归潜空间引擎（~750M）

**设计**：HRM（Hierarchical Reasoning Model）+ GRAM 双重叠加。

**双时间尺度计算**：
- **高层（慢速）**：全局逻辑、长程因果、"生成式语义"的宏观布局
- **低层（快速）**：局部高频特征（边缘、小目标）和细粒度对齐

**机器潜空间语言**：输入信号进入后，在高层和低层之间进行 K 次（如 4-8 次）的潜空间迭代更新。模型在这个阶段"默默思考"。

**稳定性保障**：HRM-Text 验证过的 MagicNorm 和渐进式深层信用分配。

### 2.3 模块 C：双流解码层（~100M）

**设计**：潜空间推理完成后，最终的 Meta-representation（元表征）同时送入两个轻量解码头。

1. **语言解释头**（LM Head）：采用 PrefixLM 方式，将潜空间最终状态作为 Prefix，自回归生成人类可读的自然语言解释
2. **生成式语义头**（轻量 DiT / Flow Matching）：将潜空间状态作为条件，生成 BEV 语义图、深度图或控制轨迹

## 3. 训练策略

### 阶段一：潜空间自监督预热
- **目标**：让模型学会"机器潜空间语言"
- **方法**：输入多模态数据，让模型在内部循环 K 次，然后要求它重建被掩码的图像 Patch 和文本 Token
- **关键**：迫使潜空间引擎学会在内部存储和推演信息

### 阶段二：仅回答目标 + 双任务对齐
- **目标**：让潜空间推理的结果能够准确映射到自然语言和语义图
- **方法**：只对最终输出的自然语言和生成的语义图计算损失，不对内部循环的中间潜空间状态施加额外约束
- **关键**：让模型自由探索最优的内部潜空间计算路径

### 阶段三：多轨迹概率推理
- **目标**：解决多模态不确定性（如路口可能左转也可能右转）
- **方法**：在潜空间迭代时，引入微小的随机噪声，生成多条不同的潜空间推理轨迹
- **关键**：综合多条轨迹的概率分布，生成最安全的语义图和解释

## 4. 关键技术点

### 4.1 显存与计算墙
- K 次内部循环意味着前向传播的计算量是 K 倍
- **解法**：梯度检查点（Gradient Checkpointing）或动态退出机制

### 4.2 潜空间坍缩（Latent Collapse）
- 在内部循环中，隐藏状态可能趋于同质化
- **解法**：MagicNorm + 时间步嵌入（Time-step Embedding）

### 4.3 数据构建
- 需要"图像/视频 + 语义图/BEV + 自然语言解释"的三元组数据
- **解法**：用 Qwen/GPT 作为教师，对 nuScenes 等开源数据集进行自动化标注
