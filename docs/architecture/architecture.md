# LatentMind 技术架构文档

## 1. 核心概念

### 1.1 什么是"机器潜空间语言"

四研究线（Logos / SADKO / Hippo / Thumos）的核心创新是：让模型在高维隐状态空间中进行多步循环迭代（Recursive Iteration），而不是输出大量离散的文本 Token。

- **传统 CoT**：模型生成大量中间文本 Token 来"思考"（浪费参数量和算力）
- **机器潜空间语言**：模型在内部通过 Hidden States 进行逻辑推演、跨模态对齐和因果计算
- **参数复用**：同一个 Transformer/SSM 层在潜空间内循环 K 次，物理参数只有 1B，但等效计算深度达到 K×

### 1.2 四研究线的核心范式

| 维度 | Logos 主线 | SADKO 探索分支 | Hippo 独立研究线 | Thumos 独立研究线 |
|------|----------|--------------|-----------------|------------------|
| **推理方式** | 分层循环 + 多轨迹推理 | 双向注意力 + Flow Matching | 双向 + FM + FSQ | 循环结构模式（agent 内化）|
| **核心创新** | H/L 双时间尺度 + Per-Token 早退 + L-PLT | 流形压缩 + 几何锚点 | FSQ 256 离散码本 + 检索 API | Intent/Fork-Join/触发内化 |
| **适用场景** | 推理 + 决策（结构化任务）| 感知 + 记忆 + 多模态（流形任务）| 记忆 / KG / 检索 | agent 能力内化 |
| **对你的价值** | 提供 latent space 推理框架 + 多假设决策 | 提供多模态流形记忆 + 知识库 | 提供持久记忆 + 知识召回 | 提供内化 agent 能力 + 低延迟 |

### 1.3 全新架构，从零训练

> 📌 **关键战略（2026-07-29 + 2026-07-31 增补）**：
> - 四研究线都是**全新架构**，**从零训练**权重
> - HRM-Text / GRAM / LoopCoder-v2 / Loop B 论文等都是**架构灵感参考**，不集成其权重
> - **64M 是起点**（MiniMind3 64M Dense 作为基座参考），不是验证
> - 规模扩展：64M → 300M → 1B → 1.5B（每级独立训练）
> - K 值是**超参数**，由 64M 验证决定
> - 64M 验证计划含 **§3.5 DiscoLoop 探针 + §3.6 Loop B 备选 + §4.6 L-PLT + §4.6.9 L-PLT+Φ**（详见 [research/logos/64m-validation-plan.md](../research/logos/64m-validation-plan.md)）

## 2. 架构详解

### 2.1 模块 A：原生统一感知层（~150M）

**设计**：借鉴商汤 SenseNova U1 的 NEO-Unify 架构思想，使用极轻量的 3 层 CNN 将图像 Patch 和文本 Token 直接映射到同一个潜空间表示中。**从零训练**。

**特点**：
- 无独立视觉编码器（VE-free）
- 像素和文字从一开始就在同一个空间"对话"
- 消除了跨模态翻译的信息损耗

### 2.2 模块 B：Logos 分层递归潜空间引擎（~750M）

**设计**：Logos 全新架构，**从零训练**。借鉴 HRM-Text 的双时间尺度循环思想 + SADKO Split-GQA 的异构 RoPE 思路。

**双时间尺度结构**：

```
H/L 双时间尺度（数学同构于 Split-GQA 的异构 RoPE）：
- H 慢速：全局逻辑、长程因果（base=500k, 类似 Split-GQA Static）
- L 快速：局部特征、细粒度对齐（base=10k, 类似 Split-GQA Dynamic）
- H/L 块各自内部采用 Split-GQA 风格（双层时间尺度）
```

**机器潜空间语言**：输入信号进入后，H/L 循环 K 次（K 是超参数，由 64M 验证决定），模型在内部"默默思考"。

**稳定性保障**：
- MagicNorm 思想（前向 PostNorm + 反向 PreNorm）
- Per-Token 早退（动态 K 调度）
- PLT 风格并行化（用于端侧 K>4 推理）

### 2.3 模块 C：双流解码层（~100M）

**设计**：潜空间推理完成后，最终的 Meta-representation（元表征）同时送入两个轻量解码头。**从零训练**。

1. **语言解释头**（LM Head）：采用 PrefixLM 方式，将潜空间最终状态作为 Prefix，自回归生成人类可读的自然语言解释
2. **生成式语义头**（轻量 DiT / Flow Matching）：将潜空间状态作为条件，生成 BEV 语义图、深度图或控制轨迹

## 3. 训练策略

### 阶段一：潜空间自监督预热
- **目标**：让模型学会"机器潜空间语言"
- **方法**：输入多模态数据，让模型在内部循环 K 次，然后要求它重建被掩码的图像 Patch 和文本 Token
- **关键**：迫使潜空间引擎学会在内部存储和推演信息

### 阶段二：仅回答目标 + 双任务对齐
- **目标**：让潜空间推理的结果能够准确映射到自然语言和语义图
- **方法**：只对最终输出的自然语言和生成的语义图计算损失，不对内部循环的中间潜空间状态施加额外约束
- **关键**：让模型自由探索最优的内部潜空间计算路径

### 阶段三：多任务对齐
- **目标**：让多模态输出与决策任务对齐
- **方法**：在多任务数据集上微调，让模型的推理能力跨越模态
- **关键**：保留 Logos 推理的涌现能力

## 4. 关键技术点

### 4.1 显存与计算墙
- K 次内部循环意味着前向传播的计算量是 K 倍
- **解法**：梯度检查点（Gradient Checkpointing）+ 动态退出（Per-Token 早退）+ PLT 并行化

### 4.2 潜空间坍缩（Latent Collapse）
- 在内部循环中，隐藏状态可能趋于同质化
- **解法**：MagicNorm 思想 + 时间步嵌入（Time-step Embedding）+ 异构 RoPE

### 4.3 数据构建
- 需要"图像/视频 + 语义图/BEV + 自然语言解释"的三元组数据
- **解法**：用 Qwen/GPT 作为教师，对 nuScenes 等开源数据集进行自动化标注
