## 一、 核心设计哲学 (Core Philosophy)

SADKO 彻底摒弃了"单脑均匀膨胀"的传统范式，确立了三大底层哲学基石：

1. **压缩即智能**：AI 的终极形态不是无限堆叠参数，而是实现更本质的知识压缩与解压。
2. **异构双脑协同**：演进法则是 **"左脑膨胀，右脑结晶"**。左脑负责"思考的深度"（离散逻辑），右脑负责"记忆的广度"（连续语义）。深度需要参数，广度只需要码字。
3. **拓扑对称性（时间之箭与时间之环）**：
   * **左脑（时间之箭）**：单向因果回归（Sequence Regression），不可逆，天然适合生成与逻辑推理链，但长程依赖衰减。
   * **右脑（时间之环）**：双向注意力 + 可逆流匹配（Flow Matching），全局感知，无方向偏好。
   * **智能的诞生**：产生于"箭射穿环"的交汇处（Cross-Attention 与扩散对齐层），实现了编码（多→少）与解码（少→多）的完美数学对称。**这一对称性更为未来跨模态（如视觉-语言）的异构融合提供了全新的几何视角**——证明全局压缩（双向）是单向生成的必要数学前提。

### 1.4 多模态流形原生（Multimodal Manifold Native）— 2026-07-29 增补

> **第一性原理声明**：SADKO 的右脑架构（双向注意力 + Flow Matching + FSQ）**从设计动机上就是为连续流形（包括图像/视频/音频/3D 点云）而生**，不是文本架构的"事后扩展"。

**为什么 SADKO 天然契合多模态**：

| 模态特性 | SADKO 对应机制 | 数学契合度 |
|---------|---------------|:---------:|
| 连续流形（像素/音频/3D） | 双向注意力（无因果 Mask）| ✅✅ |
| 可逆压缩-解压 | Flow Matching（ODE 可逆变换）| ✅✅ |
| 跨模态共享字典 | FSQ 几何锚点 + 码字嵌入 | ✅✅ |
| 局部-全局依赖 | 双向注意力 + Cross-Attention 桥梁 | ✅ |
| 增量学习 | 右脑压缩新事实 + LoRA 推理热加载 | ✅ |
| 零样本跨模态联想 | FSQ + Slerp 模糊召回 | ✅ |

**对比：循环/多轨迹范式天然不适合多模态**：

| 范式 | 适合的任务 | 不适合的任务 |
|------|----------|------------|
| 循环（HRM）| 离散逻辑推理 | 连续流形感知（K 次迭代只引入噪声）|
| 多轨迹（GRAM）| 不确定性决策 | 像素压缩（多轨迹等价于多次噪声采样）|
| 双向 + FM + FSQ | 连续流形压缩/记忆/知识 | 离散序列决策（双向破坏因果）|

**结论**：在 LatentMind 项目中，应按技术范式的数学偏置**分工**：
- **主线（HRM-Text + GRAM）**：推理 + 决策（循环/多轨迹的天然优势域）
- **SADKO**：感知 + 记忆 + 知识 + 多模态（双向/FM/FSQ 的天然优势域）

**与主线融合的接口**：SADKO 训练后冻结的 ELF Memory KV，通过 **Cross-Attention** 喂给主线 HRM 的中间层——"**HRM 是大脑皮层，ELF 是海马体**"。

**配套前置研究**：主线应先做 K-sweep 实验验证 HRM 的循环深度假设（见 [RDD-0001](../rfcs/RDD-0001-k-sweep-experiment.md)），SADKO 应先做 64M 四大机制实验（见 [64m-validation-plan.md](./64m-validation-plan.md)），避免在两条路线均未完成小规模验证前过早锁定。

详细论证见 [multimodal-native.md](./multimodal-native.md)（2026-07-29 增补）。

## 二、 架构蓝图与核心组件 (Architecture Blueprint)

SADKO-Native 采用"异构双脑 + 扩散桥梁"的三层拓扑结构。

| 组件 | 角色定位 | 核心技术实现 | 设计依据与优势 |
| :--- | :--- | :--- | :--- |
| **右脑 (ELF)** | **记忆海马体**<br>(全局语义压缩) | **双向注意力 + Flow Matching + FSQ** | 必须看到全貌才能无损全局压缩；ODE 支持可逆重构；FSQ 避免码本坍缩。 |
| **左脑 (AR)** | **逻辑皮层**<br>(单向因果推理) | **Split-GQA + 异构 RoPE + Dual-Path FFN** | 物理分割记忆与推理通路；Static 低频保长程，Dynamic 高频保时序。 |
| **桥梁 (Align)** | **胼胝体**<br>(跨模态翻译) | **Teacher-Student 扩散蒸馏** | 消除单向因果与双向流形的不兼容，实现**推理期零开销 (Zero-Overhead)**。 |
| **路由 (Router)**| **丘脑**<br>(全局注意力调度) | **Latent MoE (语义流形路由)** *(300M 完整版; 64M 用简化 hash 路由验证机制)* | 摒弃 Token 级离散路由，基于右脑全局语义向量 $z$ 路由，消除语义碎片化。64M 阶段以"2-experts + FSQ 码字 hash 路由"做最小验证（实验 E）。 |

### 2.1 右脑 (ELF)：全局语义压缩引擎

* **核心机制**：**双向注意力 + 可逆流匹配 (Flow Matching)**。全局压缩必须看到全貌（无因果 Mask），Flow Matching 支持连续流形的可逆 ODE，确保压缩与重构的数学对称性。
* **离散化接口**：**FSQ (有限标量量化)**。将连续潜向量映射为离散码本索引。码字不仅是索引，更是流形上的"锚点"，支持推理时的 Slerp 插值联想（模糊召回）。

### 2.2 左脑 (AR)：单向因果推理主干

基于 Qwen3/LLaMA 架构的核心改造：

* **Split-GQA（静态/动态 KV 分离）**：在锚点层（如第 2/4/6 层）将 KV Heads 物理劈裂（如 4 Static + 4 Dynamic），让"记忆存储"与"即时推理"在 Attention 计算内部自然分流，实现真正的 O(1) 复杂度语义解耦。
* **异构 RoPE**：Static 使用**低频（$base=500k$）**保持长程记忆，Dynamic 使用**高频（$base=10k$）**保持短程时序。设计依据对齐 NTK-aware 长上下文外推实践：更大 base = 更慢旋转 = 长程平坦注意力。
* **Dual-Path Gated SwiGLU (FFN)**：在锚点层强制分离"记忆存储"与"即时推理"通路，通过轻量门控网络动态混合。
* **Cross-Attention**：每隔 2 层插入，**绕过因果 Mask** 读取右脑的全局 Memory KV，弥补 AR 模型的长程依赖短板。

### 2.3 桥梁 (Diffusion Alignment)：胼胝体对齐

* **训练时**：小型 ELF (Teacher) 提供连续语义分布监督，AR (Student) 通过 KL+CE 损失拟合。
* **推理时**：**Zero-Overhead（零开销）**。教师模型被丢弃，连续语义感知能力已永久内化至左脑的 Embedding 空间中。通过 Cross-Attention 绕过因果 Mask 读取全局 Memory。

### 2.4 关键技术决策矩阵

| 技术维度 | 传统 LLM/RAG 方案 | SADKO 决策 | 决策依据与优势 |
| :--- | :--- | :--- | :--- |
| **信息流方向** | 全局单向因果 Mask | **左脑单向 + 右脑双向** | 右脑必须双向才能无损全局压缩；左脑必须单向以保证生成效率。 |
| **记忆注入方式** | 外部向量检索 (RAG) / Prompt 拼接 | **Cross-Attention + 扩散内化** | 避免检索割裂与上下文窗口挤占，实现原生语义理解。 |
| **潜空间离散化** | VQ-VAE / 标量量化 | **FSQ (有限标量量化)** | 避免码本坍缩，保留流形几何特性，支持码字间的平滑插值。 |
| **MoE 路由机制** | Token 级离散路由 (如 Mixtral) | **Latent MoE (语义流形路由)** | 基于右脑全局语义向量 $z$ 路由，确保同语境 Token 路由至同一专家，避免语义碎片化。 |
| **知识更新范式** | 全量微调 / 外部知识库 | **右脑记事实 + LoRA 学推理** | 右脑增量压缩陈述性知识（分钟级），LoRA 热加载程序性知识，实现零灾难性遗忘。 |

## 三、 颠覆性创新与高潜力想法 (Innovations)

以下 6 个创新点是 SADKO 区别于现有 LLM/RAG 架构的核心壁垒：

> 📌 **设计哲学增补（2026-07-29 增补 §1.4）**：SADKO 的右脑（双向 + Flow Matching + FSQ）**从第一性原理上就是为多模态流形设计的**——不是事后扩展，而是设计动机本身。本节（§三）所述创新点同样适用于多模态场景，详细论证见 [multimodal-native.md](./multimodal-native.md)。

### 1. 流形锚点与模糊联想 (FSQ + Slerp 插值)

* **传统痛点**：VQ-VAE 等离散量化只能进行精确匹配，缺乏联想能力。
* **创新**：FSQ 码字不仅是离散索引，更是连续流形上的"几何锚点"。
* **潜力**：支持推理时的球面线性插值（Slerp），模型可以在两个不相关的概念码字之间插值解码，涌现出"模糊召回"与"零样本跨域联想"能力。

### 2. 注意力内部的物理语义解耦 (Split-GQA + 异构 RoPE)

* **传统痛点**：语义解耦通常在网络外部（如 MoE 路由）或事后补救，容易破坏表征完整性。
* **创新**：在 Attention 内部将 KV Heads 物理劈裂（4 Static + 4 Dynamic），并赋予异构 RoPE（Static 低频 $base=10k$ 保长程记忆，Dynamic 高频 $base=500k$ 保短程时序）。
* **潜力**：让"记忆存储"与"即时推理"在计算底层自然分流，实现真正的 O(1) 复杂度语义解耦。

### 3. 潜空间语义路由 (Latent MoE)

* **传统痛点**：Token 级离散路由（如 Mixtral）会导致"语义碎片化"（例如"心肌梗死"中，"心"被路由到医学专家，"肌"被路由到体育专家）。
* **创新**：摒弃 Token 路由，改为基于右脑全局语义向量 $z$ 和 FSQ 码字 $c$ 的**潜空间连续路由**，整段文本被整体路由至同一专家。
* **潜力**：维持极致的语义连贯性；左脑 MoE 与右脑 ELF 共享同一连续流形几何，使跨模态对齐降维为同空间微调。

### 4. 陈述性与程序性知识的物理解耦 (右脑 + LoRA 热加载)

* **传统痛点**：知识更新要么依赖外部检索（割裂），要么全量微调（灾难性遗忘）。
* **创新**：**右脑记事实**（陈述性知识，充当"海马体"分钟级压缩新文献），**LoRA 学推理**（程序性知识，充当"突触"即时训练新领域的推理模式并热加载）。
* **潜力**：实现新领域的"即插即用"与分钟级适配，彻底解决灾难性遗忘，使模型具备有机生长能力。

### 5. 零开销的"胼胝体"蒸馏 (Diffusion Alignment)

* **传统痛点**：连续潜空间与离散 Token 空间存在"生殖隔离"，跨模态注入开销巨大。
* **创新**：训练时引入小型 ELF 作为 Teacher 提供连续语义监督，AR 作为 Student 拟合；**推理时直接丢弃 Teacher (Zero-Overhead)**。
* **潜力**：将连续语义感知能力永久内化至左脑的 Embedding 空间，推理期零额外计算成本。

### 6. "证伪驱动"的微型验证范式与负结果资产化 (64M 强约束法)

* **传统痛点**：在小模型上效果差，无法区分是"容量不足"还是"架构缺陷"。
* **创新**：在 64M 规模下删除所有冗余参数，仅保留机制计算图，并施加极强训练约束；建立《已证伪机制清单》，赋予"证明某机制无效"与"证明有效"同等的战略价值。
* **潜力**：将试错成本降低 10 倍以上，避免在 7B 阶段浪费数周算力。将"鲁棒性评分"而非"最佳性能"作为大模型投资的唯一决策依据。

### 7. 分形码本与"液态组织"隐喻

* **创新**：FSQ 码本从扁平字典演进为"分形空间"（Level 1 领域 → Level 2 概念 → Level 3 实例）。
* **潜力**：完美契合企业级知识库的生长逻辑。底层概念冻结（固态骨架），顶层实例增量学习（液态填充），**使知识更新成本降低 25 倍以上**。

## 四、 工程验证协议：64M 机制证伪 (基于 MiniMind3)

**核心原则**：64M 不是用来产出可用模型，而是用"全架构、小尺寸、强约束"证伪架构假设。遵循**消融隔离**与**强制早停**原则。

### 4.1 四大核心实验设计

| 实验 | 对照组 vs 实验组 | 核心验证目标 | 判定标准 (失败即证伪) |
| :--- | :--- | :--- | :--- |
| **A. 内容寻址** | 纯符号路由 vs 固定码本 Cosine | 内容寻址是否比纯符号有效 | 模糊查询 Recall 提升 <10% |
| **B. 拓扑缓存** | 线性 Top-K vs FSQ 排序滑动窗口 | 空间邻近性是否提升召回 | 关联查询 F1 无显著提升 |
| **C. 动态门控** | 固定 0.5:0.5 vs 动态门控网络 | 动态耦合是否优于固定混合 | 门控值始终接近 0.5 或震荡 |
| **D. 左脑校验** | 无校验 vs 生成前置信度过滤 | 校验机制是否降低错误率 | 干扰项过滤率 <50% 或误杀 >20% |

### 4.2 "病理学"诊断标准（区分容量与架构缺陷）

这是 64M 实验成败的判定宪法：

* **容量问题**：Loss 持续下降但未收敛 → 机制有效，需放大模型。
* **架构问题**：Loss 早期停滞或剧烈震荡 → 机制无效，需废弃。
* **陷阱规避**：若某机制需精调 5+ 个超参才能在 64M 勉强工作，大概率不适合工程化。**记录"鲁棒性评分"比"最佳性能"更重要。**
* **负结果资产化**：必须建立《已证伪机制清单》，避免在 7B 阶段浪费算力。

## 五、 训练流水线 (Phase 0-8)

训练的核心在于逐步注入"灵魂"，实现从机械记忆到语义理解的跨越。

* **阶段一（基石）**：Phase 0 (数据/环境) → Phase 1 (右脑 ELF 预训练) → Phase 2 (左脑基座初始化)。
* **阶段二（核心突破）**：
  * **Phase 3**：右脑 FSQ 离散化（建立流形锚点）。
  * **Phase 3.5 (机械对齐)**：让左脑学会"查字典"（FSQ 索引 → KV MSE 损失）。
  * **Phase 4 (注入灵魂)**：**扩散桥梁对齐**。ELF 教师提供连续语义分布，AR 学生通过 KL+CE 损失拟合，实现零样本跨域联想。
* **阶段三（融合）**：Phase 5 (全链路 SFT) → Phase 6 (评估抽象) → Phase 7 (制定 Scaling Law)。
* **300M 新增验证**：引入 **Latent Router** 与 **LoRA 热加载** 模块，验证语义路由一致性与新领域即时适配能力。验收标准：语义理解提升、零样本跨域联想、RAG 基准超越同参 Baseline。

## 六、 规模化演进法则 (Scaling Strategy)

SADKO 的 Scaling Law 表现为推理成本亚线性增长的 **"左脑膨胀，右脑结晶"**。

### 6.1 演进阶梯与 1.5B 中间节点

为避免 300M 直接跨越到 7B（23 倍参数量）的工程风险，**必须插入 1.5B-Bridge 节点**（成本仅为 7B 的 1/10，可提前暴露 80% 的规模化风险——特别是"码本扩展"和"分层对齐"机制在中等规模下的泛化能力）。

| 维度 | 64M (预验证) | 300M (机制验证) | 1.5B (中间 Bridge) | 7B (生产验证) |
| :--- | :--- | :--- | :--- | :--- |
| **左脑 (AR)** | ~80M（基座 64M + Split-GQA + Dual-Path FFN + CA 骨架 ~15.5M） | 300M | 1.5B | 7B | 
| **右脑 (ELF)** | 5M | 20M | 30M | 50M |
| **FSQ 码本** | 256（[8,8,4]） | 1024 (扁平) | 4096 (两级) | 8192 (两级) |
| **Cross-Attn** | L3/L5, 标量门控 init=-2 | 每2层×1，标量门控 | 标量/逐头过渡 | 每2层×2，逐头门控 |
| **对齐策略** | 全量 KL (3000 步) | 全量 KL | 分层对齐 | 分层对齐 (顶层) -> 渐进对齐 (子网络继承) |
| **核心目标** | 证伪/验证五大机制 | 证明机制正确、灵魂存在 | 暴露规模化风险 | 证明能力充分、规模可行 |

### 6.2 三大核心规模化机制

1. **右脑"冻结核"与压缩饱和曲线**：右脑压缩能力存在物理上限，参数量不随左脑线性增长。300M 阶段压缩比约 15:1，**7B 之后压缩比趋于稳定（约 8:1）**。7B 模型不需要"更聪明的压缩器"，只需要"更宽的管道"，实现推理与存储成本的**亚线性增长**。
2. **FSQ 分形码本 (Fractal Codebook)**——必须与业务逻辑严格映射，契合"液态组织"哲学：
   * **Level 1（固态骨架）**：256 个领域/概念簇（300M 学习并**永久冻结**）。
   * **Level 2（半固态）**：256 个概念子码 per 领域（7B 增量学习）。
   * **Level 3（液态填充）**：256 个具体实例 per 概念（7B 增量学习）。
   * **推理优势**：Router 先做 Level 1 粗筛，再做 Level 2 精选，避免 65536 路全搜索，实现 O(log N) 检索。训练时冻结底层概念，避免灾难性遗忘。
3. **门控机制与分层/渐进式扩散对齐**：
   * **门控演进路线**：300M（标量全局开关）→ 7B（Per-head 向量逐头门控）→ （引入小型 MLP 的内容自适应门控）。
   * **对齐演进路线**：7B 采用**分层对齐**（仅对齐顶层）；到采用**渐进对齐**——先冻结提取前 12 层作为"1.5B 子网络"复用 1.5B 对齐权重，再解冻后 16 层做增量对齐，避免大模型从零学习连续语义的巨大算力浪费。

## 七、 终极形态：可生长的认知系统

SADKO 的最终演进方向不再是传统的"大语言模型"，而是一个具备生物学特征的 **"可生长认知系统"**，彻底解决检索割裂、更新滞后与灾难性遗忘：

1. **右脑 = 长期记忆（海马体）**：负责陈述性知识，压缩存储，永不遗忘。
2. **Latent MoE = 功能区（大脑皮层）**：负责语义分区与高效推理。
3. **LoRA = 突触可塑性**：负责程序性知识。新领域文献输入后，右脑快速压缩事实，LoRA 即时训练推理模式（分钟级热加载）。
4. **Semantic Router = 丘脑**：基于右脑全局语义进行注意力调度。
5. **扩散对齐 = 胼胝体**：实现左右脑无缝的信息整合与几何对齐。

**生长原则**：

* 粗粒度新领域 → 新增 MoE Expert（结构扩展）
* 细粒度子领域 → 新增 LoRA 池（参数高效扩展）
* 纯事实更新 → 仅更新右脑（零左脑开销）

## 九、 工程落地路径 (Execution Path)

确立 **"先证伪机制，再验证能力"** 的三步走战略：

### Phase 1: 64M 机制验证 (基于 MiniMind3)

* **目标**：用"全架构、小尺寸、强约束"证伪架构假设（非产出可用模型）。
* **核心动作**：实现 `SADKOSplitGQA` 与 `Cross-Attention`。运行内容寻址、拓扑缓存、动态门控、左脑校验、简化版 Latent MoE 五大实验。
* **原则**：若机制在 64M 无效，在 300M+ 亦为伪需求；记录"鲁棒性评分"而非"最佳性能"。
* **产出**：《已验证/已证伪机制清单》（后续大模型设计的唯一宪法）。

### Phase 2: 300M 能力验证 (Phase 0-8)

* **目标**：跑通"右脑预训练 → FSQ 离散 → 机械对齐 → 扩散注入 → 全链路 SFT"全流程。
* **验收**：语义理解提升、零样本跨域联想、RAG 基准超越同参 Baseline。

### Phase 3: 7B 规模化生产

* **策略**：继承 300M 左脑权重，扩展右脑并增量训练，执行**分层/渐进式扩散对齐**（先对齐子网络再扩展），大幅降低大模型对齐成本。
