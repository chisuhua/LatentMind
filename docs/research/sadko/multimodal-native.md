## 0. 为什么这份文档存在

在 2026-07-29 之前的 SADKO 文档中（[whitepaper.md](./whitepaper.md)、[v1/v2/v3-architecture.md](./v1-architecture.md)），所有架构设计都基于**文本场景**（MiniMind3 64M + BPE vocab=6400）。这导致一个误解："SADKO 是文本认知备选"。

**事实**：SADKO 的设计动机**从一开始就是连续流形**。只是因为 64M 验证阶段选择了 MiniMind3（文本基座），才把第一版落地在文本上。

本文档从**第一性原理**出发，证明：
1. SADKO 的右脑架构与多模态流形**数学上同构**
2. 循环/多轨迹范式**不适合**多模态感知
3. 双向 + Flow Matching + FSQ 是多模态感知的**天然工具**
4. LatentMind 应按技术范式的数学偏置**分而治之**：主线 = 推理+决策，SADKO = 感知+记忆+知识+多模态

## 1. 第一性原理：连续 vs 离散的数学偏置

### 1.1 模态的数学分类

| 模态 | 本质 | 数学结构 | 偏置 |
|------|------|---------|------|
| **文本** | 离散 token 序列 | 序列、因果、可枚举 | 序列 + 收敛 |
| **图像** | 2D 像素流形 | 连续、平移等变、局部相关 | 流形 + 空间 |
| **视频** | 3D 时空流形 | 连续 + 时序因果 | 流形 + 时间 |
| **音频** | 1D 时序波形 | 连续、频域稀疏 | 流形 + 频率 |
| **3D 点云** | 不规则采样流形 | 几何、置换等变 | 流形 + 几何 |
| **知识图谱** | 离散图结构 | 节点-边、稀疏、异构 | 图 + 离散 |

### 1.2 技术范式的数学偏置

| 技术范式 | 数学偏置 | 优势域 | 不适域 |
|---------|---------|--------|--------|
| **循环推理（HRM）** | 序列 + 收敛 | 离散逻辑推理 | 连续流形感知（K 次迭代引入噪声）|
| **多轨迹采样（GRAM）** | 不确定性 + 概率 | 多假设决策 | 像素压缩（多轨迹等价于多次噪声采样）|
| **单向注意力** | 因果 + 序列 | 序列生成 | 流形全局感知（无全局视图）|
| **双向注意力** | 全局 + 空间 | 流形压缩、感知 | 离散序列决策（破坏因果）|
| **Flow Matching (ODE)** | 可逆 + 微分同胚 | 连续压缩-解压 | 离散 token 决策 |
| **VQ / FSQ 离散化** | 锚点 + 流形几何 | 跨模态字典、检索 | 高频细节（量化损失）|

**关键洞察**：每个范式都有**内在数学偏置**。把偏置不同的范式塞进同一个模块是反设计的。

## 2. SADKO 三件套的"流形原生"性

### 2.1 双向注意力 = 流形全局压缩器

**机制**：每个 patch / token 能看到所有其他 patch / token。

**为什么是流形原生**：
- 图像/视频/3D 的本质是**连续流形**上的采样，全局信息至关重要
- 因果 Mask（单向注意力）天然不适合流形——它假设"序列方向"，但流形没有方向
- 双向 = 在流形上做**全局感知**，是连续压缩的数学前提

**对比主流多模态架构**：
| 架构 | 注意力类型 | 是否流形原生 |
|------|-----------|:---:|
| LLaVA (CLIP + LLM) | 单向 LLM + 单向 CLIP | ❌ 双向 CLIP 但无全局压缩 |
| Flamingo | 单向 + 交叉注意力 | ❌ 仍以序列方向处理图像 |
| BLIP-2 | Q-Former 单向 | ❌ Q-Former 仍是序列 |
| **SADKO Hippo** | **双向 + Cross-Attention 桥梁** | **✅ 真正流形全局** |

### 2.2 Flow Matching (ODE) = 连续压缩-解压

**机制**：通过可逆 ODE 变换，在连续流形上做压缩和解压，数学上严格对称。

**为什么是流形原生**：
- 像素/音频/3D 的"压缩"本质是流形上的**微分同胚**变换
- 离散 VQ-VAE 的"压缩"是**有损量化**——破坏了流形结构
- Flow Matching 的**可逆性**保证了压缩-解压的**信息守恒**——流形结构完整保留
- 这一点对**跨模态对齐**至关重要：图像和文本的码字可以**插值**生成中间态

**对比主流多模态架构**：
| 架构 | 压缩方式 | 信息守恒 | 跨模态插值 |
|------|---------|:---:|:---:|
| VQ-VAE | 离散量化 | ❌ 量化损失 | ❌ 离散空间无插值 |
| VAE | 连续 KL 约束 | ⚠️ 部分 | ⚠️ 模糊但无结构 |
| Diffusion | 随机去噪 | ❌ 单向生成 | ❌ 无压缩 |
| **Flow Matching** | **可逆 ODE** | **✅ 严格** | **✅ Slerp 平滑插值** |

### 2.3 FSQ 离散化 = 跨模态共享字典

**机制**：有限标量量化（Finite Scalar Quantization）将连续潜向量映射为离散码字。

**为什么是流形原生**：
- FSQ 码字是**几何锚点**——在连续流形上选定的离散点
- 与 VQ-VAE 不同，FSQ **不需要**单独的码本学习——它直接绑定到几何位置
- 跨模态共享字典：图像的"猫"和文本的"cat"通过**联合训练**映射到同一锚点
- 这就是 SADKO "左脑 + 右脑" 共享码本的物理基础

**对比主流多模态架构**：
| 架构 | 跨模态对齐 | 共享字典 |
|------|----------|---------|
| CLIP | 对比学习 | ❌ 两个独立 embedding 空间 |
| BLIP-2 | Q-Former 投影 | ⚠️ 软对齐，无离散锚点 |
| CM3Leon | 共享 token | ⚠️ 文本 token，扩展视觉 |
| **SADKO** | **FSQ 几何锚点** | **✅ 真正共享字典** |

## 3. SADKO vs 主流多模态架构对比

| 维度 | LLaVA / Flamingo | BLIP-2 | **SADKO** |
|------|:---:|:---:|:---:|
| **图像编码** | 独立 ViT（CLIP/SigLIP）| Q-Former 投影 | **双向 Hippo + FM 压缩** |
| **跨模态融合** | Token 拼接 + 投影 | Q-Former 对齐 | **FSQ 共享码本 + Slerp** |
| **压缩-解压对称** | ❌ 单向生成 | ❌ 无解压 | **✅ ODE 可逆** |
| **流形全局感知** | ⚠️ ViT 双向但无全局压缩 | ❌ Q-Former 单向 | **✅ 双向 + 全局 FSQ** |
| **零样本跨域联想** | ❌ 需微调 | ❌ 需微调 | **✅ FSQ + Slerp 模糊召回** |
| **增量知识更新** | ❌ 重训 | ❌ 重训 | **✅ 右脑压缩 + LoRA 热加载** |
| **端侧部署** | ❌ 大 ViT | ⚠️ 中型 | **✅ 双向 + 共享 KV** |

**关键差异**：主流多模态架构是"**组合式**"——独立 ViT + 投影 + LLM；SADKO 是"**原生式**"——流形压缩 + 共享码本 + 双向注意力。

## 4. 循环 / 多轨迹为什么不适合多模态

### 4.1 循环（HRM）在多模态上的失败原因

| 失败机制 | 数学解释 | 现象 |
|---------|---------|------|
| **累积噪声** | K 次循环 ≈ 多次加噪 | 像素边界模糊 |
| **特征退化** | K 次投影 ≈ 信息有损变换 | 细节丢失 |
| **时延倍增** | K=8 推理 × 8 倍 | 端侧不可用 |

**HRM-Text 论文从未报告多模态实验**——这是一个**强烈的负信号**：作者也认为循环不适合多模态。

### 4.2 多轨迹（GRAM）在多模态上的失败原因

| 失败机制 | 数学解释 | 现象 |
|---------|---------|------|
| **多噪声采样** | 多轨迹 ≈ 多次随机扰动 | 像素无意义抖动 |
| **计算浪费** | 20 轨迹 × 像素计算 | 算力 × 20 但输出仍是有噪图像 |
| **不适合流形** | 流形需要 ODE 方向，不是不确定性方向 | 无法收敛到一致输出 |

**GRAM 论文只测试了符号推理任务（Sudoku/N-Queens）**——多轨迹对**离散决策**有效，对**连续流形**是浪费。

### 4.3 主流多模态架构的"折中"

主流架构（LLaVA、Flamingo、BLIP-2）选择了"**不循环 + 不多轨迹**"的折中——这从反面证明：**循环 / 多轨迹范式与多模态不兼容**。

## 5. 双轨分工：第一性原理结论

### 5.1 范式 × 任务的契合度矩阵

| 任务 \ 范式 | 循环 | 多轨迹 | 双向 + FM + FSQ |
|------------|:---:|:---:|:---:|
| 文本推理 (math/code) | ✅✅ | ✅ | ⚠️ |
| 决策规划 (多假设) | ✅ | ✅✅ | ✅ |
| **视觉感知** | ❌ | ❌ | **✅✅** |
| **跨模态对齐** | ❌ | ❌ | **✅✅** |
| **长期记忆** | ⚠️ | ❌ | **✅✅** |
| **知识库** | ❌ | ❌ | **✅✅** |
| 增量学习 | ⚠️ | ❌ | ✅ |
| 连续控制 | ✅ | ✅ | ✅ |

**结论**：
- 循环 / 多轨迹 → **推理 + 决策**（主线）
- 双向 + FM + FSQ → **感知 + 记忆 + 知识 + 多模态**（SADKO）

### 5.2 两条路线的融合接口

```
┌─────────────────── 主线 (HRM-Text + GRAM) ───────────────────┐
│  推理 + 决策（循环/多轨迹的优势域）                              │
│  接收: 共享感知主干输出 + SADKO Hippo Memory KV (via XA)         │
│  输出: 动作 / 决策 / 结构化解释                                 │
└────────────────────────┬──────────────────────────────────────┘
                         │ Cross-Attention 融合
                         ↓
┌─────────────────── 共享感知主干 (M0) ───────────────────────┐
│  原生统一感知：3 层 CNN + 模态扩展（图像/视频/音频/3D）        │
│  由 SADKO 训练后冻结，主线只读取                                │
└────────────────────────┬──────────────────────────────────────┘
                         │ 共享潜空间接口
                         ↓
┌─────────────────── SADKO 探索分支 ───────────────────────────┐
│  感知 + 记忆 + 知识 + 多模态（双向/FM/FSQ 的优势域）           │
│  输出: 共享感知主干 + Hippo Memory KV Pool                       │
│  通过 Cross-Attention 喂给主线 HRM 中间层                       │
└──────────────────────────────────────────────────────────────┘
```

**"HRM 是大脑皮层，Hippo 是海马体"**——SADKO 提供"长期记忆 + 多模态感知"，主线负责"推理 + 决策"。

### 5.3 决策原则

1. **不锁定原则**：两条路线均未完成小规模验证前，不锁定任一方向
2. **机制优先**：64M 阶段产出《已验证/已证伪机制清单》比"最佳性能"更重要
3. **融合优先**：两条路线最终应融合（Hippo KV → HRM Cross-Attention），而非互斥
4. **K 自适应**：主线 K 不是固定超参，应根据任务难度 + per-token 收敛状态动态调整

## 6. 多模态 SADKO 的具体实施路径

### 6.1 64M 阶段（当前）

**MiniMind3 64M 文本基座**（见 [64m-validation-plan.md](./64m-validation-plan.md)）：
- v1.0：左脑改造（Split-GQA + 异构 RoPE + Dual-Path FFN）
- v2.0：MemPool 压缩-读取管线
- v3.0：Hippo-Lite + FSQ + 扩散对齐 + 四大实验

**完成后**：产出《已验证/已证伪机制清单》。

### 6.2 300M 阶段（中期）

**300M 双脑融合**：
- 文本基座 → 多模态扩展（图像 + 文本）
- 验证 70/20/10 黄金比例（KV 输入比例，见 [hippo-graph-emergence.md §4](./hippo-graph-emergence.md)）
- 验证 FSQ 码字的跨模态对齐（图像"猫" + 文本"cat" → 同一码字）

**关键实验**：
| 实验 | 目标 | 验证 |
|------|------|------|
| 图像 → FSQ 码字 | MNIST 压缩成 256 码字 | 码字间是否形成有意义的语义流形 |
| 文本 → 同一码字 | 对应文本也压到相同码字 | 跨模态锚点对齐 |
| 码字 → 图像重构 | Flow Matching 从码字生成图像 | 验证可逆性 |
| 码字 → 文本生成 | PrefixLM 从码字生成描述 | 验证跨模态生成 |

### 6.3 1B+ 阶段（远期）

**双脑完整融合**：
- 1B 端侧推理核（主线 FP16）
- 1.5B 多模态记忆核（SADKO INT8 KV 缓存）
- Cross-Attention 融合接口（端侧零开销）

## 7. 风险与缓解

| 风险 | 概率 | 影响 | 缓解 |
|------|:---:|:---:|------|
| **SADKO 64M 机制证伪** | 中 | 高 | 双轨并行，主线不依赖 SADKO |
| **多模态扩展算力爆炸** | 中 | 高 | 从 MNIST 起步，逐步到 CIFAR → ImageNet |
| **FSQ 码本坍缩** | 中 | 中 | EMA 更新 + 死码重启 |
| **跨模态对齐失败** | 中 | 高 | 70/20/10 黄金比例 + 对比学习辅助 |
| **融合接口时延** | 低 | 中 | 端侧 SADKO KV 缓存 INT8 + 稀疏读取 |
